BUILD A COMPLETE PROFESSIONAL WEB APPLICATION

PROJECT NAME:

SOMALI DISABILITY DATA ENTRY

============================================================
1. PROJECT OVERVIEW
============================================================

Build a complete, professional, secure, responsive web-based
Disability Data Entry and Management System called:

"SOMALI DISABILITY DATA ENTRY"

The system is designed to digitally register and manage
disability-related information for up to 200 people.

This system replaces a manual Excel-based data-entry process.

The application must be a REAL working application, not a visual
prototype or fake demo.

All data must be stored persistently in a real database.

The system must work on:

- Desktop
- Laptop
- Tablet
- Android
- iPhone

The UI must automatically adapt to different screen sizes.

============================================================
2. MAIN OBJECTIVE
============================================================

The administrator must be able to:

- Login securely
- Register a person
- Store their information
- View all registered people
- Search records
- Filter records
- View individual records

- Delete records
- Export data to Excel
- Import existing Excel data
- Backup data
- Backup Excel files to Google Drive
- Restore/import previous data
- View statistics
- Manage administrator account
